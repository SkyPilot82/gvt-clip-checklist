# GVT Clip Checklist

A shot list for GVT Studio clips, laid out like the takes folder:
`takes/<place>/<battle-type>/<file-name>-<portrait|landscape>.mp4`.

Open it at https://skypilot82.github.io/gvt-clip-checklist/

- Tick a shot when it's recorded. Ticks, notes and your own shots stay in your browser (use **Backup** to move them).
- **Copy for Claude** copies a full set-up (place, units, items, timed events, camera steps, start timer, health) to paste into a Claude session.
- **Naming + folders** shows the naming rules and the whole folder map.

Built from GVT Studio r37 (game v30.28) with the r38 camera, start timer and health tools in mind. Places the Studio can't load right now are left out.
